# NovaRetail File Storage, Sharing, and Backup

- Document ID: NR-IT-019
- Owner: Service Desk
- Version: 1.0
- Last reviewed: 2026-10-15
- Audience: Employees saving or sharing company work files

## Purpose

Use this guide to choose NovaRetail OneDrive or SharePoint storage, share files with controlled access, and recover deleted or changed work without relying on local-only storage.

## Save NovaRetail work in OneDrive or SharePoint

NovaRetail work files belong in OneDrive or SharePoint. Files saved only on a laptop's local disk are not backed up, even when the company laptop is encrypted.

- Use OneDrive for work you manage individually.
- Use SharePoint for team-owned files that colleagues must retain and maintain.
- Check synchronization or upload completion before shutting down or handing over a laptop.
- Do not use personal cloud storage or personal email for company files.
- Microsoft 365 file access does not require NovaConnect VPN.

Personal phones are approved only for Authenticator, Outlook, and Teams under app protection; do not install OneDrive or SharePoint work apps on BYOD. Use a company device for approved file-storage work.

## Share NovaRetail files with controlled recipient access

NovaRetail file sharing must match the data classification and intended recipients. Use a OneDrive or SharePoint link restricted to named recipients rather than a public link.

1. Confirm the file's classification and the recipient's need for access.
2. Use the file's available sharing controls to specify the intended recipients.
3. Grant viewing rather than editing unless editing is required.
4. Check the recipient list and link settings before sending.
5. Remove access when the work is complete.

External sharing requires resource-owner and Security team approval before granting access. Do not email a copy to bypass blocked sharing. If a recipient sees access denied, verify the approved account and permissions rather than widening access for everyone.

## Share large NovaRetail files without email attachments

Large NovaRetail files should be shared through OneDrive or SharePoint instead of multiple email attachments. NovaRetail email allows a combined attachment file size of 20 MB per message.

1. Upload the file to the appropriate company OneDrive or SharePoint location.
2. Wait for the upload or synchronization to finish.
3. Create a link restricted to the intended recipients.
4. Set the minimum needed viewing or editing permission.
5. Send the link and confirm that recipients can open the approved file.

Do not split a sensitive document across messages to evade controls or use a personal file-transfer service. If an upload fails, report the file size, company storage location, and exact error without attaching the sensitive contents.

## Recover deleted or changed NovaRetail work files

NovaRetail OneDrive and SharePoint deleted files can be recovered from their recycle bins within 93 calendar days of original deletion. A later move between recycle-bin stages does not restart that period.

1. Open the relevant company OneDrive or SharePoint location.
2. Use its recycle-bin controls to find the deleted file.
3. Restore the intended item and confirm its content and location.
4. For unwanted changes to an existing file, use version history to restore a saved version.
5. Contact the Service Desk if the file or required recovery option is unavailable.

Include the filename, location, and deletion or change time. Recovery is not guaranteed after permanent deletion or 93 days. This window does not extend the 30-calendar-day leaver preservation period.

## Check NovaRetail file protection before a device handover

NovaRetail file protection depends on work reaching OneDrive or SharePoint, not simply having a copy on an encrypted laptop. Check work storage before refresh, repair, or a loaner handover.

1. Identify required work files saved in local folders.
2. Move individually managed work to OneDrive and team-owned work to SharePoint.
3. Wait for synchronization or upload completion.
4. Open the saved files from the company storage location to confirm availability.
5. Report failed synchronization before handing over the device.

Do not use USB storage for transfer; it is blocked by default and exceptions need a ticket and manager approval. If the laptop will not start, tell the Service Desk where local-only files were stored; recovery is not assured.

## Frequently asked questions

**Q: Where should I save my work documents?**
A: Use NovaRetail OneDrive for individually managed work and SharePoint for team-owned work. Confirm synchronization; local-disk-only files are not backed up.

**Q: What's the secure way to send a file?**
A: Create a NovaRetail OneDrive or SharePoint link for named recipients with minimum permissions. External sharing needs resource-owner and Security approval.

**Q: I deleted a file. Can I get it back?**
A: Restore a NovaRetail OneDrive or SharePoint file from its recycle bin within 93 calendar days of original deletion. Contact the Service Desk if recovery is unavailable.

**Q: Is everything on my laptop backed up?**
A: No. NovaRetail files saved only on the laptop's local disk are not backed up. Encryption and company ownership do not create a backup.
