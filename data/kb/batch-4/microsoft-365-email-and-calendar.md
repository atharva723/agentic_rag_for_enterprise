- Audience: Employees using company Outlook mailboxes and calendars

## Purpose

Use this guide to manage NovaRetail Outlook email, mailbox space, shared mailboxes, calendar sharing, and automatic replies using company-approved access.

## Use NovaRetail Outlook and email attachment limits

NovaRetail Outlook uses your company Microsoft 365 account and does not require NovaConnect VPN. Sign in with your company email, password, and MFA.

- The combined file size of email attachments must not exceed 20 MB per message.
- Use a OneDrive or SharePoint sharing link for files exceeding that limit.
- Check recipients before sending and use only approved access to company files.
- Review junk mail for legitimate messages, but do not open suspicious links or attachments.
- Report suspected phishing to `security@novaretail.example` without interacting with the message.

For mail that fails to send, record the error and attachment size for the Service Desk. An attachment within the limit can still be rejected by recipient or security controls.

## Free space in a NovaRetail Outlook mailbox

A NovaRetail individual Outlook mailbox has a 50 GB quota. A full mailbox needs content management, not a personal mailbox as a workaround.

1. Check mailbox storage information using Outlook's available mailbox controls.
2. Find large attachments and unneeded messages.
3. Preserve required work files in OneDrive or SharePoint before removing email copies.
4. Delete mail that is no longer required for company work.
5. Empty deleted items only after confirming they are not needed.
6. Recheck mailbox storage and test sending.

Do not forward a mailbox to personal email or export company mail to personal storage. If required content prevents reducing usage, submit the storage reading and error at `https://itportal.novaretail.example` for assessment.

## Add a NovaRetail shared mailbox in Outlook

A NovaRetail shared mailbox requires manager and mailbox-owner approval before the Service Desk assigns access. Reading the mailbox and sending as the mailbox are separate permissions.

1. Request the mailbox and required permissions at `https://itportal.novaretail.example`.
2. Allow the standard access target of 2 business days after complete approvals and details.
3. After confirmation, reopen Outlook using your own company account.
4. If the mailbox is not displayed, use Outlook's available shared-mailbox addition controls to enter the approved mailbox address.
5. Check that the approved reading or sending action works.

A shared mailbox does not have a password for employees to share. If it remains unavailable, update the access ticket with the mailbox address and error.

## Share a NovaRetail Outlook calendar appropriately

NovaRetail Outlook calendar sharing should expose only the information needed for company coordination. Start with availability-only access rather than giving another employee edit access to all appointments.

1. Open the company calendar in Outlook.
2. Use the available calendar-sharing controls to choose the intended company recipient.
3. Select the minimum appropriate detail or permission level.
4. Send the invitation and confirm that the recipient can view the intended information.
5. Remove sharing when it is no longer needed.

Do not share a company calendar publicly or with an unapproved external recipient. For a shared calendar requiring team permissions, submit a manager and resource-owner access request. Include the calendar name and whether viewing or editing is needed.

## Set a NovaRetail Outlook out-of-office reply

A NovaRetail Outlook out-of-office reply provides availability information without disclosing sensitive schedules or company data. Use Outlook's available automatic-reply controls rather than creating a password-sharing arrangement.

1. Open automatic replies for your company mailbox.
2. Enable replies and set the required start and end times.
3. Write a brief internal message explaining when you will respond.
4. If external replies are enabled, use a shorter message without internal details.
5. Name an approved company contact only if that person has agreed to handle the work.
6. Save the settings and confirm the configured period.

Do not include personal travel details, credentials, or confidential project information. An automatic reply does not grant the named contact mailbox access.

## Frequently asked questions

**Q: What's the biggest attachment I can email?**
A: NovaRetail email allows a combined attachment file size of 20 MB per message. Share larger files through an appropriately restricted OneDrive or SharePoint link.

**Q: How do I turn on out-of-office replies?**
A: Use Outlook automatic-reply controls for your NovaRetail mailbox, set the start and end times, write an appropriate message, and save. Keep external replies free of internal details.

**Q: How do I add a shared mailbox?**
A: Request NovaRetail manager and mailbox-owner approval, then use Outlook's shared-mailbox controls after access confirmation. Specify reading and sending permissions in the request.

**Q: My mailbox is full. What's the limit?**
A: NovaRetail individual mailboxes have a 50 GB quota. Preserve required files in OneDrive or SharePoint, remove unneeded mail, and review deleted items before emptying them.
