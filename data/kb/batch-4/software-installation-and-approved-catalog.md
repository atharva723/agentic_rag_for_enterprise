# NovaRetail Software Installation and Approved Catalog

- Document ID: NR-IT-016
- Owner: Service Desk
- Version: 1.0
- Last reviewed: 2026-10-15
- Audience: Employees and managers requesting company software

## Purpose

Use this guide to install approved NovaRetail software, request an app missing from Software Center, and understand licensing and prohibited installation methods.

## Install approved NovaRetail software from Software Center

NovaRetail software must be installed through Software Center on a company device. Company laptops have no local admin rights, and approved packages handle the permitted installation process.

1. Save active work and connect the company device to a reliable network.
2. Open Software Center and search for the required application.
3. Read the package description and any work-role requirements.
4. Select `Install` and allow the installation to finish.
5. Restart if requested, then open the application.

If installation fails, report the application name and error through `https://itportal.novaretail.example`. Do not download an alternative installer or ask another employee for admin credentials. IT never requests your password or an MFA code.

## Find an app in the NovaRetail approved catalog

NovaRetail Software Center categories are `Productivity`, `Collaboration`, `Business Applications`, `Accessibility`, and `Device Utilities`. You can also search by app name.

- `Productivity` contains approved document and everyday work tools.
- `Collaboration` contains approved communication tools, including Teams.
- `Business Applications` contains approved role-specific business tools.
- `Accessibility` contains approved tools that support accessible device use.
- `Device Utilities` contains approved connectivity, printing, and accessory packages.

NovaConnect VPN and `NovaRetail Printing` are company-managed packages, not internet downloads. Installing an app does not grant system permissions. Request access separately if company sign-in reports access denied.

## Request software missing from NovaRetail Software Center

NovaRetail software missing from Software Center must be requested through `https://itportal.novaretail.example` and needs manager plus Security team approval. The request target is 2 business days.

1. Provide the software name and the work task it must support.
2. Explain why an existing catalog application cannot meet the requirement.
3. State the device type and employees who need the app.
4. Identify any company data the software would process.
5. Submit the request with your manager and retain the ticket number.

Business days are Monday through Friday, excluding company holidays. Wait for both approvals and approved packaging before installation. A submitted request or passed target does not authorize downloading the software yourself.

## Use NovaRetail software licenses correctly

NovaRetail software licenses are assigned for approved company work and must not be shared, transferred to personal accounts, or reused on unapproved devices. The Service Desk coordinates license assignment with the software request.

1. Request the application through Software Center or the NovaIT Portal, as appropriate.
2. Use your own company account when the application requires sign-in.
3. Report a license or activation error with the application name and displayed message.
4. Tell the Service Desk when an assigned application is no longer needed.

Do not send license credentials or activation secrets in a ticket. If the app opens but access to a company resource fails, request the necessary manager and resource-owner permissions instead of using a colleague's account.

## Recognize prohibited NovaRetail software installations

NovaRetail prohibits software installed outside the approved company process, even when the installer is free or the employee already has a personal license.

- Do not install personal VPN clients or streaming apps on company devices.
- Do not install unapproved remote-access, cleanup, or security-bypass tools.
- Do not use modified installers or software that bypasses licensing.
- Do not install a personal operating system or disable device management.
- Do not run a downloaded portable application to avoid installation approval.

If a tool is needed for legitimate work, request it through `https://itportal.novaretail.example` for manager and Security approval. Report an unexpected installer or suspected unauthorized software to the Service Desk; suspected compromise goes to `security@novaretail.example`.

## Frequently asked questions

**Q: How do I install an app on my work laptop?**
A: Install NovaRetail-approved software from Software Center using `Install`. Report installation errors instead of downloading another installer.

**Q: The software I need isn't in Software Center. What now?**
A: Submit a NovaRetail software request with the app name, business reason, device type, and data involved. Manager and Security team approval are required.

**Q: How long does a software request take?**
A: NovaRetail's new-software request target is 2 business days, Monday through Friday excluding company holidays. Installation remains prohibited until approvals and approved packaging are complete.

**Q: Can I install a personal VPN or streaming app?**
A: Personal VPNs and streaming apps are prohibited on NovaRetail company devices. Use the approved company catalog and request legitimate work software through the NovaIT Portal.
