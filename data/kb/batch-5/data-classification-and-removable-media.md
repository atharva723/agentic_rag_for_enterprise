# NovaRetail Data Classification and Removable Media

- Document ID: NR-IT-023
- Owner: Security team
- Version: 1.0
- Last reviewed: 2026-10-15
- Audience: Employees and contractors storing, sharing, or transferring company data

## Purpose

Use this guide to identify NovaRetail data classes, apply handling restrictions, and request a controlled exception to the USB-storage block.

## Identify the four NovaRetail data classes

NovaRetail data uses four classes: Public, Internal, Confidential, and Restricted. Ask the resource owner to classify uncertain material before sharing it more widely.

- Public: approved material intended for publication, such as published store opening hours.
- Internal: employee work instructions and routine operating procedures not approved for public release.
- Confidential: unpublished product-launch plans or supplier operating plans limited to authorized recipients.
- Restricted: customer-identifying records or security recovery material requiring the tightest access.

A draft is not Public just because a similar finished document was published. If a file combines classes, apply the most protective class present. Do not invent a lower classification to make a transfer easier or bypass a sharing restriction.

## Handle NovaRetail data according to its class

NovaRetail data handling must reflect its classification and the recipient's work need, even when the file is stored on an encrypted company device.

- Public material must be approved for publication before being treated as public.
- Internal material stays within approved company access unless external sharing is approved.
- Confidential material uses named-recipient permissions and is limited to authorized work.
- Restricted material stays in its approved company location and must not be shared externally or copied to USB.

Store work in OneDrive or SharePoint and grant only the required viewing or editing access. Do not use personal email or cloud storage. Report a classification or access-control question through `https://itportal.novaretail.example` before transferring uncertain data.

## Share NovaRetail Confidential data outside the company

NovaRetail Confidential data must not be sent outside the company in an email body or attachment. Approved external transfer uses a named-recipient OneDrive or SharePoint link after resource-owner and Security team approval.

1. Request approval through `https://itportal.novaretail.example`.
2. Identify the file classification, recipient, business purpose, and access end date.
3. Wait for both approvals before granting access.
4. Create a link limited to the approved recipients and minimum permissions.
5. Remove external access when the approved work ends.

External file sharing also requires approval for Public and Internal files. Restricted data must not be shared externally. An email size limit or successful upload is not authorization to release company information.

## Understand the NovaRetail USB-storage block

NovaRetail USB storage is blocked by default on company devices. A USB drive owned by the company, an employee, or another organization is not automatically approved for use.

- Do not use removable storage to move files during laptop refresh or repair without an exception.
- Do not change device controls or use another port to bypass the block.
- Do not copy Restricted data to USB, even when another USB exception exists.
- Use OneDrive or SharePoint instead for normal work-file transfer.
- Standard keyboards, headsets, and docking stations are not USB storage, but must still be approved accessories.

If a legitimate task cannot use company file storage, submit an exception request with the work reason rather than trying an unapproved drive.

## Request a NovaRetail USB-storage exception

A NovaRetail USB-storage exception requires a ticket and manager approval before IT enables the specified use. An approval for one task is not blanket permission for every device or data class.

1. Submit the request at `https://itportal.novaretail.example`.
2. State the business reason, company device, data class, intended recipient, and required end date.
3. Obtain manager approval.
4. Use only the company-approved encrypted drive and scope recorded in the ticket.
5. Ask IT to remove the exception when the approved task ends.

For external data transfer, resource-owner and Security approval are also required; Restricted data remains prohibited. If an approved drive does not work, update the exception ticket instead of changing device security settings.

## Frequently asked questions

**Q: What are the company data classes?**
A: NovaRetail uses Public, Internal, Confidential, and Restricted. Apply the most protective class present in a mixed file and ask the resource owner if classification is unclear.

**Q: Can I email Confidential data to someone outside?**
A: No, not in the email body or as an attachment. NovaRetail requires resource-owner and Security approval, followed by a named-recipient OneDrive or SharePoint link.

**Q: Can I plug in a USB drive to copy work files?**
A: NovaRetail USB storage is blocked by default. Obtain a ticketed, manager-approved exception first; Restricted data cannot be copied to USB.

**Q: What should I put in a USB exception request?**
A: Give the NovaRetail business purpose, device, data class, recipient, and end date. After manager approval, use only the approved encrypted drive within the ticket's scope.
